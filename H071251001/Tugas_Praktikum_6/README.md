# Portofolio Praktikum 6 — React + Vite + Tailwind CSS

## Menjalankan project
1. Ekstrak ZIP.
2. Buka folder project di VS Code.
3. Pastikan Node.js dan npm sudah terpasang.
4. Jalankan `npm install`.
5. Jalankan `npm run dev`.
6. Buka alamat lokal yang ditampilkan Vite di terminal.

## Sesuaikan sebelum dikumpulkan
- Ganti `Nama Kamu`, status, fokus, dan domisili di `src/components/Hero.jsx` dan `src/components/About.jsx`.
- Tambahkan foto profil milik sendiri bernama `profile.jpg` ke folder `public/`.
- Tambahkan minimal empat foto milik sendiri bernama `gallery-1.jpg` sampai `gallery-4.jpg` ke `src/assets/gallery/`.
- Ubah teks galeri agar sesuai dengan foto yang dipakai.

## Kesesuaian dengan instruksi
- React + Vite, SPA.
- Enam komponen terpisah: Navbar, Hero, About, Skills, Gallery, Footer.
- Semua komponen memakai `export default` dan nama fungsi kapital.
- Data daftar disimpan dengan `const` dan dirender memakai `.map()` dengan key sesuai instruksi.
- Navbar dan tombol Hero memakai `onClick` dan `console.log`.
- Tidak menggunakan `useState` atau `props`.
- Styling menggunakan Tailwind CSS dan responsif untuk layar kecil.
- Foto galeri diimpor dari `src/assets/gallery`; foto profil dipanggil dari `public/`.

Catatan: file gambar pribadi tidak disertakan. Tambahkan foto sendiri sebelum dijalankan agar sesuai instruksi tugas.
