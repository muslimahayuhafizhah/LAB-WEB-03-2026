# Portfolio — Muh. Alief Nur Afanni Arfan

Website portofolio pribadi yang dirancang untuk menampilkan profil, keahlian, dan karya visual/digital.

## 🚀 Tech Stack

- **Framework:** [React 19](https://react.dev/)
- **Bundler:** [Vite](https://vite.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)

## 📂 Fitur Utama

- **Hero & Persona:** Pengenalan diri singkat dan fitur pratinjau & unduh CV.
- **Skills & Expertise:** Ringkasan keahlian teknis dan alat yang dikuasai.
- **Gallery:** Showcase karya visual, fotografi, dan desain.
- **Responsive & Modern Design:** Tampilan responsif dan minimalis di semua ukuran layar.
